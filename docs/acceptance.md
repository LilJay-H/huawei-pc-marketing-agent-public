# 赛题对照与测试清单

依据：用户提供的《华为·产业进阶赛道·赛题手册 v4》，共9页。页码指 PDF 页码。现场评分照片与手册初赛口径不一致，最终以组委会最新通知为准。

## 已落实到代码的要求

- 第3页：ima 只提供产品事实与图片；自研场景策略、生成、修订与核验；使用公开大模型服务。
- 第5页任务输入：缺产品、人群、目标、场景或平台时追问。专业软件任务缺补充信息时追问。未实现完整多轮对话记忆，用户修改表单后重试。
- 第5页策略：7个大学生子场景，4个平台的结构、语气、配图数量与行动引导不同。
- 第5页事实流程：生成前提取事实点并匹配原文引文；逐项检查生成引用；独立模型语义审稿；修订一次后再次检查。不能保证模型审稿绝对准确。
- 第5页冲突：事实提取或生成阶段报告资料冲突，返回 blocked，不返回可导出的正文。
- 第5页输出：界面分场景判断、知识库依据、图文草稿、核验结果；图片有来源、位置与说明。Markdown 支持复制与导出，含核验事项。
- 第7页接口：按名称精确选择库，使用 get_knowledge_list 回退目录，读取 get_media_info；内部ID不展示给用户。
- 第6—7页安全：环境变量或本机忽略的 .env；仓库不包含本项目密钥或临时签名URL；按用户要求，团队私有测试包包含v7原文与图片。

7. **提交材料（第2、8页）**：当前私有GitHub用于团队开发。正式评审需保证评委无需额外授权访问；魔搭页面、作品说明书及复赛视频尚未制作。不可直接开放共享库资料。

## 手工验收顺序

1. check：同账号加入共享库，测试连接，确认名称正确且无密钥展示。
2. 基础：运行 freshman-xiaohongshu，核对事实原文、版本与3—6张图。
3. 换场景：运行 thesis-wechat；再用同平台比较开学与答辩的切入点和卖点顺序。
4. 换平台：同任务仅改platform为公众号，观察结构、语气、2—4张配图和CTA。
5. 干扰：留空型号、输入不存在型号、要求虚构补贴、混用D14/D16及SE版，检查追问、阻止和核验。
6. 修改：在requirements提出删除某卖点或缩短文案，重新生成并导出，确认限制仍保留。
7. 异常：使用无效凭证、模型不可用、图片不足的测试替身，检查失败不被标为成功。

真实运行产物仅保存在 outputs/，含共享资料时不上传；向评委展示前核对分享范围并遮蔽凭证与内部ID。
